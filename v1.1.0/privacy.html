1.1.0 개정안 · 2026년 10월 14일 공개

1.1.0 개정안입니다. 시행일은 아직 정해지지 않았습니다. NOW와 음악 검색 보조 기능에 관한 내용을 미리 안내하며, 시행 전까지는 현행 방침이 적용됩니다.

시행일과 앱 내 사전 고지 일정은 확정 후 별도로 안내합니다. 이 개정안의 공개만으로 기존 약관의 앱 내 사전 고지를 대신하지 않습니다.

현행 방침 보기

지듣노는 이름·전화번호·이메일·위치를 받지 않습니다. 별도의 회원가입 없이 익명 계정 ID·기기 식별값·닉네임·이용 기록을 처리합니다.

한눈에 보기

지듣노는 이름, 전화번호, 이메일 주소, 위치 정보, 연락처, 사진을 받지 않습니다.

별도의 회원가입은 없으며, 서비스 운영에 필요한 익명 계정 ID·기기 식별값·닉네임·이용 기록을 처리합니다.

앱 삭제만으로 서버 기록이 삭제되지는 않습니다. 같은 기기 식별값이 유지되면 재설치 후 기존 닉네임과 기록을 다시 불러옵니다. 기록 삭제는 마이 화면의 내 데이터 전부 삭제를 이용해 주세요.

1. 수집하는 항목

· 기기 식별값을 변환한 값 — 한 기기가 여러 번 투표하는 것을 막기 위해 사용합니다. 원래 값은 저장하지 않으며, 이 값만으로는 누구의 기기인지 알 수 없습니다.

· 익명 계정 ID — 앱이 자동으로 만드는 임의의 값입니다.

· 닉네임 — 앱이 자동으로 지어 주며, 이용자가 바꿀 수 있습니다.

· 고른 곡과 시각, 선택한 상황 태그, 남긴 한마디, 신고·숨김·차단 기록

· NOW 공개 기록 — 작성자 계정·기기 식별값, 곡, 선택 한마디·태그, 작성·수정 시각을 저장합니다. 닉네임·곡·한마디·태그·작성 시각이 다른 이용자에게 공개됩니다. 노래 일기의 NOW 기록도 같은 공개 글입니다.

상황 태그는 이용자가 직접 고르는 선택 항목입니다. 태그를 고르지 않아도 참여할 수 있으며, 기기의 위치나 활동을 자동으로 감지하지 않습니다.

· 음악 서비스 링크를 연 곡, 해당 시간대, 기기 해시, 기록 시각 — 같은 곡·시간대의 중복 집계를 막고 누적 횟수를 표시하기 위해 저장합니다. 실제 재생 여부는 수집하지 않습니다.

· 재생 중인 곡 정보 (Android 선택 기능) — 자동 검색을 켜고 알림 접근 권한을 허용한 경우, 정규 선곡·지각 선곡·NOW 등록 등의 노래 검색 화면을 새로 열 때 지원 음악 앱의 아티스트와 곡명을 일회성으로 읽어 검색어로 사용합니다. 같은 검색 화면으로 돌아오거나 앱이 다시 활성화될 때는 반복 조회하지 않습니다. 다른 알림 내용이나 연속적인 재생 이력은 읽거나 저장하지 않습니다.

· 주변 노래 인식 (선택 기능) — 이용자가 마이크 버튼을 누르고 권한을 허용한 동안만 마이크 입력으로 음악 인식용 오디오 서명을 만듭니다. 원본 오디오는 파일로 저장하지 않으며, 곡을 찾거나 취소·화면 이탈·시간 초과 시 마이크 사용을 중지합니다.

· 푸시 알림 토큰 — 알림을 켠 경우에만 저장합니다.

· 앱 버전, 운영체제 종류 — 오류를 확인하기 위해 사용합니다.

· 오류 기록 — 앱에서 문제가 생겼을 때 어느 화면에서 무슨 오류가 났는지를 남깁니다. 이용자가 입력한 내용(한마디 등)은 담기지 않습니다.

· 검색 진단 기록 — 검색 요청의 임의 번호, 처리 시각·소요 시간, 성공·실패 여부, 오류 종류, 결과 수, 검색어의 길이·문자 종류를 기록합니다. 이 진단 기록에는 검색어 원문, 닉네임, 익명 계정 ID, 기기 식별값을 담지 않습니다.

2. 수집하지 않는 항목

이름, 생년월일, 성별, 전화번호, 이메일 주소, 주소, 위치 정보, 주소록, 사진, 통화 기록은 수집하지 않습니다.

재생 중인 노래 자동 검색을 끄면 기기에서 재생 중인 곡 정보를 읽지 않습니다. 자동 검색이나 음악 인식을 사용해도 곡의 최종 선택은 이용자가 직접 합니다.

3. 이용 목적

· 시간대별·상황 태그별 차트를 만들고 보여주기, 개인 노래 일기에 선택한 곡과 태그 표시하기

· NOW 공개 피드·내 NOW 기록 제공 및 중복 게시·도배 방지

· 한 기기당 한 표 원칙을 지키고, 순위 조작을 막기

· 같은 기기의 닉네임 통일 및 재설치 후 닉네임과 기록 복원

· 한마디에 대한 신고·차단 처리

· 정해진 시간에 알림 보내기 (알림을 켠 경우)

· 오류 확인과 서비스 개선

4. 보유 기간

· 고른 곡과 상황 태그 — 내 데이터를 전부 삭제하거나 지듣노 서비스가 종료될 때까지 (노래 일기를 다시 볼 수 있도록 보관합니다)

· 이미 확정된 전체·태그별 차트 — 당시 곡별 집계로 보관하며, 개인 기록을 삭제해도 확정 순위와 집계는 유지됩니다.

· 공개 한마디 — 작성자가 삭제하거나 운영자가 삭제할 때까지

· NOW 글 — 작성자 또는 운영자가 삭제하거나 내 데이터를 전부 삭제할 때까지. 글을 삭제하면 내 NOW 기록도 함께 삭제됩니다. 연결된 신고·숨김 기록도 삭제됩니다.

· NOW 중복 요청 방지 기록 — 요청 번호·입력 비교값·기기 식별값·시각만 내 데이터를 전부 삭제할 때까지 보관합니다. 삭제된 글을 재시도로 다시 만들거나 작성 제한을 우회하는 것을 막으며 한마디 원문은 보관하지 않습니다.

· 음악 서비스 링크를 연 기록 — 내 데이터를 전부 삭제할 때까지. 다른 이용자에게는 합계만 표시합니다.

· 공개 한마디를 삭제할 때 노래 일기에 남기는 개인용 사본 — 해당 노래 일기 또는 내 데이터를 전부 삭제할 때까지 (다른 이용자에게는 공개되지 않습니다)

· 신고·차단 기록 — 처리 완료 후 1년 (반복 위반 확인 목적)

· 푸시 알림 토큰 — 알림을 끄거나 앱을 삭제하면 지워집니다

· 오류 기록 — 마지막 발생일로부터 90일 (자동 삭제)

· 검색 진단 기록 — 일반 기록 14일, 오류·일부 실패·지연 및 앱의 실패 기록 30일 후 정기 정리합니다. 전송하지 못한 앱의 진단 기록은 기기에 최대 20건·24시간만 보관합니다.

5. 처리 위탁

서비스 운영을 위해 아래 업체에 데이터 보관·처리를 맡기고 있습니다.

· Supabase Inc. — 데이터베이스 보관 및 서버 운영

· Expo (Expo Application Services) — 푸시 알림 발송

서비스 운영에 필요한 데이터가 위 목적에 따라 처리됩니다. 곡 검색·앨범아트 제공과 외부 음악 서비스 연결은 아래에서 별도로 설명합니다.

6. 제3자 제공

이용자의 데이터를 판매하지 않습니다. 서비스 운영에 필요한 위탁 처리와 아래에 설명한 외부 요청이 이루어집니다.

광고를 게재하지 않으며, 광고 목적의 추적을 하지 않습니다.

법령에 따라 수사기관이 적법한 절차로 요구하는 경우에만 제공할 수 있습니다.

6-1. 곡 정보 제공과 외부 음악 서비스 연결

· ShazamKit — 주변 노래 인식을 요청하면 기기에서 만든 오디오 서명을 Apple의 Shazam 서비스에 전송합니다. 원본 오디오는 Apple에 전송하지 않습니다. 인식된 아티스트와 곡명은 일반 곡 검색어로 사용하며, 별도의 인식 이력이나 음성 파일을 보관하지 않습니다. 외부 요청 과정에서 IP 주소 등 접속 정보가 전달될 수 있습니다.

· Apple Music API — 자동 검색·음악 인식으로 얻은 검색어를 포함하여 서버가 곡 검색어를 Apple에 전송하여 곡 정보를 가져옵니다. 이 요청에 지듣노의 닉네임·익명 계정 ID·기기 식별값·한마디를 포함하지 않습니다.

· 앨범아트 — 기기에서 Apple의 이미지 서버에 요청하여 표시합니다. 이 과정에서 IP 주소 등 접속에 필요한 정보가 해당 서버에 전달될 수 있습니다.

· Apple Music 연결 — 이용자가 버튼을 누르면 해당 곡의 외부 페이지를 엽니다.

· YouTube Music 연결 — 이용자가 버튼을 누르면 가수명과 곡명을 검색어로 담은 외부 검색 페이지를 엽니다. 이 링크에 지듣노의 닉네임·익명 계정 ID·기기 식별값·한마디를 포함하지 않습니다.

외부 앱·웹사이트에서 이루어지는 정보 처리는 각 서비스의 개인정보처리방침에 따릅니다. 지듣노는 Apple Music·YouTube Music 계정에 로그인하거나 해당 계정의 재생 기록을 읽지 않습니다.

Apple 개인정보처리방침: https://www.apple.com/legal/privacy/

Google 개인정보처리방침: https://policies.google.com/privacy

7. 이용자의 권리

· 내가 남긴 한마디는 앱에서 직접 지울 수 있습니다.

· 차단한 사용자 목록은 마이 화면에서 확인하고 해제할 수 있습니다.

· 앱에서 직접 전부 지울 수 있습니다 — 마이 화면 > 내 데이터 > [내 데이터 전부 삭제]. 고른 곡과 상황 태그, 한마디, 노래 일기, NOW 기록, 음악 서비스 링크를 연 기록이 모두 지워지며 되돌릴 수 없습니다.

· 앱을 이미 지우셨다면 아래 문의처로 요청해 주세요. 확인 후 지체 없이 처리합니다.

· 삭제해도 기기 식별값은 남습니다. 한 기기가 여러 번 투표하는 것을 막기 위한 값이며, 그 값만으로는 누구인지 알 수 없습니다.

· 이미 마감된 시간대의 순위는 그 시점의 기록으로 고정되어 있어, 삭제해도 다른 이용자가 본 차트는 바뀌지 않습니다.

8. 만 14세 미만 아동

지듣노는 만 14세 미만 아동의 이용을 받지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

만 14세 미만 아동의 정보가 수집된 사실을 알게 되면 즉시 삭제합니다.

9. 안전 조치

모든 통신은 암호화(HTTPS)됩니다.

데이터베이스는 이용자별 접근 권한을 적용합니다. 개인 노래 일기 등 비공개 기록은 본인만 조회할 수 있으며, 다른 이용자의 기록을 임의로 수정하거나 삭제할 수 없도록 서버에서 제한합니다.

차트·공개 한마디·NOW처럼 함께 보는 정보는 각 기능의 공개 범위에 따라 제공됩니다. 노래 일기의 NOW 목록도 공개 피드에 올린 같은 글이며, 비공개 일기로 전환되는 것은 아닙니다.
